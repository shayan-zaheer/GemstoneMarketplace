# 🏆 Gemstone Marketplace  

A blockchain-powered platform for buying and selling gemstones as NFTs, ensuring secure transactions through smart contracts and escrow.  

## 🚀 Features  

- **MetaMask Integration** – Users register with their crypto wallets.  
- **NFT Gemstone Listings** – Buyers can publish gemstones as NFTs.  
- **Smart Contracts & Escrow** – Secure transactions with automatic handling.  
- **Certificate Verification** – Government-issued certificates are verified via API.  
- **Physical Shipment Validation** – NFTs and payments are only released after confirmation.  

## 🛠️ Tech Stack  

- **Blockchain:** Ethereum  
- **Smart Contracts:** Solidity  
- **Frontend:** Next.js
- **Backend:** Node.js (Express)  
- **Database:** SQL Server  
- **Wallet Integration:** MetaMask  
- **NFT Storage:** IPFS / Pinata
